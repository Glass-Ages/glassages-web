The publishing tool

Only the operator of Glass Ages uses the tool, and only on the channel's own accounts. It collects no data from other people and has no users besides the operator.

  • YouTube (Google): The tool uses the YouTube Data API with the scopes youtube.upload and youtube.force-ssl. It uses them only for the operator's own channel: to upload videos, add captions, thumbnails and playlist entries, set publishing dates, and post the channel's own comment.
  • Instagram (Meta), X and Bluesky: The tool publishes the channel's own posts to the channel's own accounts.

The tool stores only the access credentials for these accounts (for example an OAuth refresh token), on the operator's own server with restricted access. It does not sell or share this data, does not use it for advertising, and does not use it to train AI models.

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. The tool's access can be revoked at any time at myaccount.google.com/permissions.
